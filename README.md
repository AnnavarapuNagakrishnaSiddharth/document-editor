📄 Document Editor Web Application

A fast and modern web-based document editor that lets users write, format, and convert documents to PDF directly from the browser. Built with React on the frontend and Node.js on the backend, with Python integration for PDF support.

🚀 Features

✍️ Create and edit documents online

🧾 Real-time formatting & smooth text handling

💾 Server-based document storage

📥 Convert edited documents to downloadable PDF

⚡ Fast, clean, and responsive UI (React)

🔐 Keeps files private on server — no third-party uploads

🛠 Tech Stack
Layer	Technology
Frontend	React, Vite
Backend	Node.js, Express
PDF Conversion	Python
Storage	Local server uploads
